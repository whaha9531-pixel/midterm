📈 二次函數平移互動探究器 (填充題第 4 題視覺化)

拖曳下方滑桿，動態觀察拋物線向右、向下平移時，標準式與頂點坐標的即時變化：

水平平移 (向右為正): +2 單位
垂直平移 (向下為負): -3 單位
原始圖形: f(x) = (x - 3)² - 1，頂點 (3, -1)
正確移動後: f(x) = (x - 5)² - 4，頂點 (5, -4)
你寫的答案: (x - 1)² - 4，頂點 (1, -4) (錯誤向左偏了4單位！)
💡 視覺化結論： 當你寫成 $(x - 1)^2 - 4$ 時，頂點位於 $(1, -4)$，其實是從原本的 $(3, -1)$「向左平移 2 單位」，與題目要求的「向右平移 2 單位」正好反向！因此向右平移必須是減 2：$(x - 3 - 2)^2 = (x - 5)^2$。

⚖️ 一元二次不等式圖形解析 (計算題第 7 題視覺化)

方程式 $2x^2 + 5x - 3 = 0$ 的兩根為 $x = -3$ 與 $x = \frac{1}{2}$。請看拋物線在 $x$ 軸上下的分界：

拋物線: y = 2x² + 5x - 3 (開口向上)
負值區域 (y < 0，x 軸下方): -3 < x < 0.5 (正解)
你的誤寫: -0.5 < x < 3 (兩根正負號弄反)
🚨 避錯核心： 解 $(2x - 1)(x + 3) = 0$ 時： $$2x - 1 = 0 \implies 2x = 1 \implies x = +\frac{1}{2}$$ $$x + 3 = 0 \implies x = -3$$ 在考卷上寫下兩根後，先在數線上標出 $-3$ 在左、$0.5$ 在右，小於 0 夾在中間，答案自然是 $-3 < x < \frac{1}{2}$！
